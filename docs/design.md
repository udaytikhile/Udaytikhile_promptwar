# Blind Spot — Design

- **Mood**: Calm, reflective, mirror-like — helps you see yourself clearly
- **Palette**: Dark ink #0F1115 bg, warm off-white #F5F0EB text, amber #F2B544 accent
- **Card colors**: Assumptions amber #F2B544, Overlooked teal #3ECFB4, Conflicts coral #F27961, Questions violet #B49CFF
- **Fonts**: Fraunces (display/heading) + Inter (body) via next/font
- **Layout**: Single-page vertical flow — input → analysis cards → follow-up → clipboard export
- **Signature element**: Evidence quotes styled as "mirror reflections" — small quoted excerpts proving each insight comes from the user's own words
