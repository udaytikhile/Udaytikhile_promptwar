# Blind Spot — Design

- **Mood**: Calm, serene, mirror-like clarity — helps you see your thoughts honestly on a crisp studio canvas
- **Palette**: Clean stone-canvas #FAFAFA, pure white surface #FFFFFF, deep ink text #18181B, warm amber #B45309 accent
- **Card colors**: Assumptions amber #B45309, Overlooked teal #0F766E, Conflicts coral #C2410C, Questions violet #6D28D9
- **Fonts**: Fraunces (display/heading) + Inter (body) via next/font
- **Layout**: Single-page focused vertical flow — input → analysis cards → follow-up → clipboard export
- **Signature element**: Evidence quotes styled as reflective excerpts ("You wrote: ...") proving each insight is grounded in the user's own words
